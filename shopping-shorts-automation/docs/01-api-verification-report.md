# 쇼핑쇼츠 제휴 자동화 시스템 — 1차 공식 API 검증 보고서

- 작성일: 2026-10-14
- 조사 방법: Opus(오퍼스) 리서치 에이전트 5기 병렬 조사 (인포크링크 / 줍줍·대안 서비스 / 쿠팡 파트너스 API / Meta Instagram API / 전략 대안)
- 판정 기준: **공식 확인**(공식 문서 원문 확인) / **조건부**(공식 가이드 인용·미러 등 2차 근거) / **미확인**(근거 부족) / **미지원**(공식적으로 없음 확인)
- 조사 한계: 일부 사이트(partners.coupang.com 로그인 영역, 공정위 원문 등)는 직접 열람하지 못해 '조건부'로 표기함. 구현 전 해당 계정으로 로그인해 원문 재확인 필요.

## 0. 최종 결론 요약 (가장 중요)

> **"인포크링크 자동 등록"은 공식 방법이 존재하지 않는다.**
> 운영사 에이비제트㈜의 공식 FAQ에 "링크를 추가하는 API는 아직 없습니다"라고 명시되어 있다.
> (출처: https://abz.gitbook.io/inpocklink/faq — 미지원 **공식 확인**)

따라서 원래 계획(인포크링크 API 자동 등록)은 폐기하고, 아래 **더 좋은 대안**으로 설계를 변경할 것을 권고한다.

### 더 좋은 아이디어 (권장 순)

**1안 (최선): 쿠팡 인플루언서 공식 기능 + 자체 랜딩페이지 혼합**
- **쿠팡 인플루언서 프로그램**(influencers.coupang.com)이 이미 우리가 만들려던 것과 같은 기능을 **공식 제공**한다:
  - **'내 스토어'**: 상품 모음 페이지 (인포크링크의 상품 블록 역할)
  - **'자동 DM'**: 인스타 댓글 키워드 감지 → 쿠팡 구매링크 자동 DM 발송
  - 심사제이며 수수료율은 파트너스와 동일 (출처: https://influencers.coupang.com/announcements/209)
- 프로필 링크용으로는 **자체 랜딩페이지**(Railway/Vercel 배포)를 하나 만들어 인스타·유튜브 프로필에 고정 URL로 걸어둔다. 영상번호별 구매링크 게시·수정·품절 교체·클릭 통계를 **우리 DB와 코드로 100% 자동화**할 수 있다. 이것이 제3자 API 없이 완전 자동화가 되는 유일한 경로다.
- 정책 리스크가 가장 낮다 (쿠팡 공식 기능 + 자기 소유 페이지).

**2안 (차선): 인포크 생태계 유지 + 반자동**
- 댓글 자동 DM: **인포크매니저**(월 18,900원, Meta API 기반 공식 확인) 또는 **ManyChat**(매니챗) Pro — ManyChat은 External Request(외부 서버 HTTPS 호출)로 우리 백엔드와 연동 가능.
- 프로필 링크: 인포크링크 **수동 등록** + 우리 관리 프로그램은 "등록 체크리스트"만 관리. 스마트스토어 상품은 공식 '스마트스토어 블록'으로 반자동 가능.
- "완전 자동 등록"은 포기. 브라우저 자동화로 인포크 관리자 화면을 조작하는 방식은 약관(업무방해·동의 없는 영리 이용 금지, 강제탈퇴 조항) 및 robots.txt의 /admin 차단 때문에 **비권장**.

**3안 (보조): 직접 Meta API 개발**
- 기술적으로 공식 구현 가능하나, 실사용 댓글 웹훅(webhook, 실시간 알림 수신)을 받으려면 **앱 Live 전환 + Advanced Access 앱 심사 + 비즈니스 인증**이 필요. 1인 운영자에게는 진입 장벽이 가장 크다. 1·2안 운영 후 장기 과제로.

### B. '줍줍' — **서비스 미확정, 연동 차단 유지**

| 후보 | 정체 | 제휴링크 서비스인가 |
|---|---|---|
| jupjup.app | 무료 경품 응모 이벤트 모음 | 아님 |
| 줍줍 리워드앱(Google Play) | 앱테크 포인트 앱 | 아님 |
| 줍줍마켓 | 중고매물 통합 검색 | 아님 |
| 오늘의줍줍(신한카드) | 앱테크 | 아님 |
| 줍줍페(제주항공) | 이벤트명 | 아님 |

→ "크리에이터가 제휴링크를 등록하는 서비스"로서의 '줍줍'은 **발견되지 않음**. 사용자가 말한 '줍줍'이 혹시 **쿠팡 인플루언서 '내 스토어'**, 지그재그 공유리워드, 리틀리 등을 가리키는지 **실제 URL 또는 앱 화면 확인 필요**. 확인 전까지 줍줍 어댑터(adapter, 서비스별 연결 모듈)는 **비활성(차단)** 상태로 둔다. — 절대 규칙 준수.

### D. 쿠팡 파트너스 Open API

| 항목 | 판정 | 내용 |
|---|---|---|
| 제공 상태 | 조건부 | 운영 중으로 보임. 문서는 partners.coupang.com/#help/open-api (로그인 필요). 키 발급: Tools → 파트너스 API |
| **사용 자격** | 조건부 | **"최종 승인된 파트너스 회원"만** 사용 가능. 누적 판매 15만 원 도달 시 최종 승인 검토(2차 인용). 승인 전엔 파트너스 메일로 예외 검토 요청 가능 |
| 상품 검색 API | 조건부 | GET …/products/search?keyword= → productId, productName, productPrice, productImage, productUrl, isRocket 등. 가격 필터 미지원 |
| 딥링크 API | 조건부 | POST …/deeplink — coupangUrls(+선택 subId) → shortenUrl. 상품명·가격·이미지는 안 줌 |
| 리포팅 API | 조건부 | 클릭/주문/수익/취소 4종, 조회 30일 이내, 매일 15시 갱신. **subId(하위 ID)로 영상별 성과 추적 가능** |
| 인증 | 조건부 | HMAC-SHA256 서명 (CEA 방식, GMT 시각+메서드+경로+쿼리) |
| **호출 제한** | 조건부 | **검색 시간당 약 10회**, 전체 분당 100회, 웹 링크 생성 분당 50회(2020 공지 기준, 2025 후기 일치). 초과 시 24시간 차단, 경고 3회 누적 시 이용 제한 → **실시간 검색 불가, 사전 수집·캐시(cache, 미리 저장) 구조 필수** |
| WING(판매자용)과 구분 | 공식 확인 | WING Open API(developers.coupang.com)는 판매자 전용 — 계정·키·용도 전부 다름. WING 키로 딥링크 생성 불가 |
| 수동 링크 생성 | 조건부 | 승인 전에도 웹에서 가능(상품 검색/URL 붙여넣기 → 간편링크 복사). "API 활용은 필수 아님" |

## 2. 실제 자동화 가능 범위

### 완전 자동화 가능 ✅
1. 쿠팡 상품 검색 → 후보 제시 (파트너스 API 최종 승인 후 / 시간당 ~10회 제한 → 큐+캐시 구조)
2. 제휴 딥링크 생성 + subId로 영상번호 태깅
3. **자체 랜딩페이지에 영상번호별 구매링크 자동 게시·수정·삭제** (인포크링크 대체)
4. 품절·판매중지 감지 → 발송 보류 + 교체 후보 생성
5. 클릭·주문·수익 통계 자동 수집 (리포팅 API + subId)
6. 인스타 댓글 키워드 → 1회 자동 DM (쿠팡 인플루언서 공식 기능, 또는 인포크매니저/ManyChat, 또는 장기적으로 직접 Meta API)
7. 중복 발송 차단, 발송 로그, 대가성 문구 자동 삽입

### 반자동 (사람 확인 필요) ⚠️
1. 동일 상품 판정 최종 확인 (후보 제시까지 자동, 확정은 사람)
2. 품절 시 대체 상품 승인
3. 인포크링크를 계속 쓸 경우: 수동 등록 + 프로그램은 체크리스트 관리

### 사람이 반드시 해야 함 ❌
1. 쿠팡 파트너스 가입·실적 15만 원 달성·최종 승인 / 쿠팡 인플루언서 신청
2. 활동 채널 등록 (자체 페이지 URL 포함)
3. 영상 제작·업로드, 캡션 첫 줄 대가성 문구 (템플릿으로 반자동화 가능)
4. 인스타 프로필 링크 최초 1회 설정 (IG User API는 읽기 전용 — 프로필 수정 API 없음)
5. 유튜브 고정 댓글·Shopping 상품 태그 (Studio 수동)
6. Meta/쿠팡 정책 변경 모니터링, 계정 재인증

### 자동화 금지 (절대 규칙) 🚫
- 인포크링크 관리자 화면 브라우저 자동 조작 (약관 위반 위험)
- '줍줍' 연동 (서비스 미확정 — 차단 유지)
- 승인 없는 대량 DM, 클릭 없는 자동 리다이렉트
- 비공식 Linktree "API" 등 존재 미확인 API 사용

## 5. 리스크 목록

1. **쿠팡 파트너스 운영정책 원문 미열람** — 메신저/DM 허용 범위, 외부 단축 URL 허용 여부는 로그인 후 원문 확인 + 고객센터 서면 답변 확보 권장 (위반 시 수익 몰수·계정 해지)
2. 파트너스 API 키는 최종 승인 전 발급 불가 → 초기에는 수동 링크 생성으로 운영하는 단계적 계획 필요
3. 검색 API 시간당 ~10회 → 실시간 검색 설계 불가, 사전 수집·캐시 필수
4. 인스타 DM 제약: 댓글당 1회·7일 이내·비팔로워는 요청함 폴더(도달률 저하)
5. 대가성 고지: 단정형 문구를 캡션 첫 줄·DM 첫 문장·페이지 상단에 — 위반 시 공정위 제재 대상
6. 신규 도메인 랜딩페이지가 인스타에서 차단되는 사례(일화 수준) → 사전 테스트
7. '줍줍' 미확정 → 사용자 확인 전 연동 차단 유지
8. 쿠팡 인플루언서 승인 기준 비공개 → 탈락 시 2안으로 운영
